# تنفيذ الإكمال — Spark Finance & Studio Manager

## السلطة والنطاق

- المصدر المعماري: `docs/ARCHITECTURE.md` و`docs/adr/ADR-002-backup-and-google-drive.md`.
- نطاق الإكمال: M5 الاستوديو، M6 لوحة التحكم والتقارير، M7 النسخ الاحتياطي المحلي والاستعادة الآمنة وإعدادات Google Drive، ثم حزمة Tauri لويندوز.
- لا يوجد تغيير في مبدأ offline-first: لا اتصال شبكي أثناء عمل المالية أو الاستوديو أو SQLite. Google Drive عامل اختياري منفصل بعد نجاح النسخة المحلية.

## معايير القبول

1. حجوزات الاستوديو تدعم الإنشاء والعرض والتعديل والإلغاء والإكمال، والحجز المتكرر، وتمنع التداخل داخل معاملة.
2. لوحة التحكم والتقارير تقرأ أرقامًا حية من SQLite ولا تعرض أرقامًا ثابتة.
3. النسخة المحلية تلتقط SQLite والمرفقات باستمرارية، تشمل manifest وSHA-256، تحتفظ بآخر 30 نسخة، وتنفذ نسخة قبل الاستعادة والتحقق قبل استبدال الملفات.
4. Drive اختياري وغير حاجب، ولا تحفظ رموزه في SQLite أو ملفات نصية.
5. يمر TypeScript وESLint والاختبارات والبناء، ثم تجربة Tauri/Windows الفعلية.

## مخاطر وبوابات توقف

- رفع Google Drive الفعلي يحتاج OAuth Desktop Client مخصصًا للتطبيق وredirect URI مصرحًا به؛ لا يجوز اختراع أو تضمين بيانات اعتماد.
- إضافة Rust crates أو Tauri plugins قد تتطلب تنزيل تبعيات. لا يتم نشر أو رفع أي شيء عن بعد ضمن هذا العمل.
- الاستعادة عملية مدمرة بطبيعتها، لذا تبقى محكومة بتأكيد صريح ونسخة أمان سابقة.
